# /draft-agenda

Read meetings, committee-actions, interests and treasurer-review first. Write the agenda to drafts. Review the constitution notice period and recipient list. This does not issue a meeting notice.

Run:

```bash
node scripts/club.mjs draft-agenda <meeting>
```

Use --json when combining results. On an ambiguous match, list the candidates and ask the operator to choose. Never select the first match. Nothing in this recipe sends, publishes or processes a payment.
